# Faded Memories Scratch

이 폴더는 당신의 어린 시절 이야기와 심리 분석, 전체 흐름을 정리하기 위한 공간입니다.

작업을 시작하기 전에는 가능하면 `.agent/WORKFLOW.md`를 먼저 보고, 같은 기준으로 이어서 작성합니다.

## 폴더 구성

- `story/` - 어린 시절 사랑 이야기를 쓸 파일
- `story/episodes/` - 에피소드별로 기억을 나눠 기록하는 곳
- `psychology/` - 나와 상대방의 심리를 분석하는 파일
- `psychology/episodes/` - 에피소드별 심리 분석을 정리하는 곳
- `flow/` - 이야기 전체를 소설처럼 엮을 흐름 정리 파일
- `flow/episodes/` - 에피소드별 흐름을 계획하는 곳

## 다음 단계

1. 새로운 기억이 생기면 `story/episodes/`에 에피소드를 추가합니다.
2. 같은 번호의 심리 분석 파일을 `psychology/episodes/`에 함께 만듭니다.
3. 같은 번호의 흐름 메모 파일을 `flow/episodes/`에 함께 만듭니다.
4. 각 파일에서는 `Fact`, `Interpretation`, `Unknown`을 가능하면 구분합니다.
5. 필요하면 에피소드별 제목과 내용을 함께 정리합니다.
