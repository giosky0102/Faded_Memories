# Faded Memories Scratch

이 폴더는 당신의 어린 시절 이야기와 심리 분석, 전체 흐름을 정리하기 위한 공간입니다.

## 폴더 구성

- `story/` - 어린 시절 사랑 이야기를 쓸 파일
- `story/episodes/` - 에피소드별로 기억을 나눠 기록하는 곳
- `psychology/` - 나와 상대방의 심리를 분석하는 파일
- `psychology/episodes/` - 에피소드별 심리 분석을 정리하는 곳
- `flow/` - 이야기 전체를 소설처럼 엮을 흐름 정리 파일
- `flow/episodes/` - 에피소드별 흐름을 계획하는 곳
