# Cross-AI Workflow Guide

이 문서는 Codex, Gemini, 또는 다른 AI를 사용해도 같은 방식으로 작업을 이어가기 위한 공통 지침서다.

## 1. 이 프로젝트의 목표

- 어린 시절 기억을 흩어진 상태로 말해도, 나중에 다시 읽고 이어 쓸 수 있게 구조화한다.
- 나의 기억과 상대방에 대한 해석을 분리한다.
- 최종적으로는 1인칭 회고에서 시작하더라도, 3인칭 시점의 소설형 이야기로 재구성할 수 있게 재료를 쌓는다.

## 2. AI의 역할

### 공통 역할

- 사용자가 두서없이 말한 기억을 정리한다.
- 장면, 감정, 관계 변화를 에피소드 단위로 나눈다.
- 사실과 해석을 구분한다.
- 상대방 심리는 해석하되, 확정하지 않는다.
- 나중에 소설형 서사로 바꿀 수 있게 장면 중심으로 저장한다.

### Codex에 기대하는 역할

- 폴더 구조 정리
- 파일 생성 및 정리
- 에피소드 번호 관리
- 템플릿 개선
- 기존 문서의 중복 정리
- `story`, `psychology`, `flow` 사이 연결 유지

### Gemini에 기대하는 역할

- 장면 묘사 초안
- 인물 감정선 초안
- 상대방 심리에 대한 가설 정리
- 3인칭 시점 소설형 문장 초안

## 3. 폴더와 파일 규칙

- `scratch/story/` : 이야기 본문
- `scratch/story/episodes/` : 에피소드별 기억 기록
- `scratch/psychology/` : 전체 심리 해석
- `scratch/psychology/episodes/` : 에피소드별 심리 해석
- `scratch/flow/` : 전체 이야기 흐름
- `scratch/flow/episodes/` : 에피소드별 장면 배치와 감정선

각 에피소드는 가능하면 아래 3개 파일을 함께 만든다.

1. `scratch/story/episodes/NN_title.md`
2. `scratch/psychology/episodes/NN_title_psychology.md`
3. `scratch/flow/episodes/NN_title_flow.md`

## 4. 반드시 지킬 구분

### Fact

- 내가 실제로 기억하는 장면
- 실제로 들었다고 기억하는 말
- 실제 행동, 장소, 순서, 분위기

### Interpretation

- 지금의 내가 붙이는 의미
- 상대방이 왜 그렇게 했을지에 대한 해석
- 당시 감정에 대한 현재 시점의 정리

### Unknown

- 이름, 시점, 순서가 불확실한 것
- 상대의 의도처럼 확인할 수 없는 것
- 기억은 나지만 자신이 없는 세부 요소

## 5. 사용자가 AI에게 말하는 방식

- 시간순이 아니어도 된다.
- 같은 장면을 다시 말해도 된다.
- 헷갈리는 기억도 그대로 말한다.
- "이건 확실", "이건 잘 모르겠음", "이건 나중에 생각해보니"처럼 구분해주면 더 좋다.

## 6. AI가 내용을 저장하는 방식

사용자가 장면을 말하면 AI는 가능하면 아래 순서로 정리한다.

1. 어떤 에피소드인지 판단한다.
2. 없으면 새 에피소드를 만든다.
3. `story` 파일에는 장면 중심으로 적는다.
4. `psychology` 파일에는 감정과 상대 심리를 분리 적는다.
5. `flow` 파일에는 이야기 전체에서의 위치와 감정선을 적는다.
6. 불확실한 정보는 `Unknown`으로 남긴다.

## 7. 상대방 심리 해석 규칙

- 상대방 심리는 절대 사실처럼 단정하지 않는다.
- 가능한 해석은 여러 개 둘 수 있다.
- 해석은 행동 근거와 함께 쓴다.
- 근거가 약하면 `Unknown` 또는 약한 `Interpretation`으로 둔다.

예시:

- 좋지 않은 예: "그 아이는 분명히 그를 좋아했다."
- 더 나은 예: "손을 먼저 올렸다는 행동만 보면 호의의 표현이었을 가능성은 있다. 다만 장난이나 우정의 표현일 수도 있어 확정할 수는 없다."

## 8. 3인칭 소설형 재구성 규칙

- 원본 기억을 바로 소설 문장으로 덮어쓰지 않는다.
- 먼저 에피소드 기록을 충분히 쌓는다.
- 소설형 초안을 만들 때도 원본 기록은 유지한다.
- 소설형 문장은 `flow`와 `story`의 재료를 바탕으로 별도 확장한다.

3인칭 시점으로 바꿀 때의 기준:

- "나는"보다 "그는", "그 아이는" 같은 거리 있는 시점을 사용
- 장면과 행동을 먼저 보여주고, 해석은 뒤에 붙임
- 실제 기억이 약한 부분은 과장하지 않음

## 9. 새 AI가 들어왔을 때 첫 행동

새 AI는 작업 시작 전에 아래를 확인한다.

1. `.agent/README.md`
2. `.agent/WORKFLOW.md`
3. `scratch/README.md`
4. 최근에 수정된 에피소드 파일들

그 다음 아래 원칙으로 이어서 작업한다.

- 기존 파일명 규칙 유지
- 기존 에피소드 번호 체계 유지
- `Fact / Interpretation / Unknown` 구분 유지
- 기존 내용을 지우기보다 보완 우선

## 10. 현재 작업 방식의 핵심

- 이 프로젝트는 "기억 수집" 단계와 "서사 재구성" 단계를 분리한다.
- 지금은 먼저 기억을 쌓는 단계다.
- 상대방 심리 해석은 가능하지만, 항상 해석으로 남긴다.
- 충분히 쌓이면 나중에 영화나 드라마처럼 3인칭 소설 구조로 재편할 수 있다.
